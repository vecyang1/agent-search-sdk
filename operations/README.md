# Operations

Use this folder for repeatable runbooks, live non-secret connection routes,
local setup, deployment notes, automation cadence, and maintenance procedures.

Examples:

| Path Example | Purpose |
| --- | --- |
| `operations/runbooks/local-dev.md` | How to run the project locally. |
| `operations/runbooks/deploy.md` | Deploy and rollback procedure. |
| `operations/health-checks.md` | Runtime checks and expected outputs. |
| `operations/links.md` | Non-secret admin URLs and dashboards. |
| `operations/cadence.md` | Scheduled jobs, automation owners, retry/success markers, cost/risk notes, and review cadence. |

Never commit secrets here. Put secret names and lookup routes only.
